# EPUBox 法律页面文案与上线说明

本目录为 EPUBox（中文技术 EPUB 电子书商城）准备的整套法律页面文案，面向 **WordPress + WooCommerce** 后台使用。

文案按已确认的业务事实起草：**中国大陆经营主体**、**支付宝/微信支付**、**数字商品仅故障类退款**、**译本不声称已获原作品商业授权**。所有法条引用均已核对官方或法院公开文本。

## 二、发布步骤（修复 WooCommerce「页面没有设置」提示）

### 第 1 步：创建页面

1. 后台 → **页面 → 新建页面**。
2. 页面标题按上表填写（Terms and Conditions / Refund Policy / Privacy Policy / Copyright Policy / Digital Download Guide）。
3. **固定链接**按上表设置（页面属性 → 固定链接）。
4. 粘贴正文：
   - **推荐方式**：用浏览器打开对应的 `.html` 文件 → 全选复制 → 在 WordPress 编辑器中直接粘贴，WordPress 会自动转换为区块结构。
   - **备选方式**：在编辑器右上角切换到「代码编辑器」模式，粘贴文件全部源码。
5. 发布。

### 第 2 步：在 WooCommerce 中指定页面

后台 → **WooCommerce → 设置 → 高级 → 页面设置**：

| WooCommerce 选项 | 选择 |
|---|---|
| 条款和条件（Terms and conditions） | `Terms and Conditions`（`/terms-and-conditions/`） |
| 隐私政策（Privacy policy） | `Privacy Policy`（`/privacy-policy/`） |

保存后，WooCommerce 的「页面没有设置」提示即消失。

> 隐私政策若使用 WordPress 自带的「隐私政策」草稿页，请把本目录的内容合并进去，并保留站内相对链接。

### 第 3 步：结账页勾选框文案（**关键，不可省略**）

WooCommerce 默认的勾选框文案只写「我已阅读并同意条款和条件」。对数字商品，**勾选框必须同时构成"消费者在购买时确认不适用七日无理由退货"的确认程序**，否则该格式条款对消费者不产生约束力。

**区块结账（Checkout block）**：
后台 → **WooCommerce → 设置 → 高级 → 页面设置** → 勾选「显示条款和条件」；再编辑 **「结账」区块 → 条款和条件**，把文案改为：

> 我已阅读并同意《条款和条件》，并知悉本店商品为在线交付的数字化电子书，下载完成后不适用七日无理由退货，详见《退款政策》。

**经典结账（`[woocommerce_checkout]` 短代码）**：在**子主题**的 `functions.php` 中加入过滤器：

```php
add_filter( 'woocommerce_get_terms_and_conditions_checkbox_text', function () {
	$terms = get_permalink( wc_get_page_id( 'terms' ) );
	$refund = get_permalink( wc_get_page_id( 'refund-policy' ) );

	return sprintf(
		'我已阅读并同意 <a href="%1$s">《条款和条件》</a>，并知悉本店商品为在线交付的数字化电子书，下载完成后不适用七日无理由退货，详见 <a href="%2$s">《退款政策》</a>。',
		esc_url( $terms ),
		esc_url( $refund )
	);
} );
```

> `wc_get_page_id( 'refund-policy' )` 需要先把《退款政策》页面设置为自定义页面，并确保其 slug 为 `refund-policy`；若 slug 不同请一并替换。

### 第 4 步：商品页的数字化标注（**关键，不可省略**）

依据《网络购买商品七日无理由退货暂行办法》第二十条，对不适用七日无理由退货的商品，**销售者应当采取技术手段予以明确标注**。

对每个商品：

1. 编辑商品 → **商品数据 → 一般**，勾选 **虚拟（Virtual）** 和 **可下载（Downloadable）**（虚拟商品不触发配送流程）。
2. 编辑商品 → **通用**，在**简短描述**或**描述**末尾加入固定文案：

> 本商品为在线交付的数字化 EPUB 电子书，支付成功后通过下载链接交付，不适用七日无理由退货。详见《条款和条件》与《退款政策》。

3. 编辑商品 → **商品数据 → 下载**，设置：
   - **下载限制**：填 `3`（与文案中的 `{{下载次数上限}}` 保持一致）
   - **下载链接有效期**：填 `30 天`（与 `{{下载有效期}}` 保持一致）
4. **账户 → 设置 → WooCommerce → 数字产品 → 下载权限**：选择「授予权限」或「所有已购买的用户」，确保付款后客户确实能拿到下载链接。

### 第 5 步：补充站内固定元素

- **首页**：显著位置持续公示营业执照信息（名称、统一社会信用代码、经营地址），符合《电子商务法》第十五条。
- **网站底部**：公示 ICP 备案号（{{ICP备案号}}）。
- **联系页面**：邮箱、电话、服务时间与上述文案一致。

## 五、必须正视的两个风险

### 5.1 版权风险（本项目最大的上线障碍）

当前文案按「**不声称已获原作品商业授权**」起草——这是诚实且必要的，但请明确：

> **免责声明不能免责。** 依《著作权法》第五十三条，未经著作权人许可复制、发行、通过信息网络向公众传播作品的，应当承担停止侵害、赔偿损失等责任。多家法院在判决中明确指出，「仅供交流使用」「如有侵权联系删除」等声明不能免除侵权责任。支付宝、微信支付也可能在收到权利人投诉后冻结商户结算。

也就是说，写一份完善的版权政策只能降低损害，不能把商业模式变成合法经营。可选的合规路径，按投入从低到高：

1. **转向「按需翻译服务」模式**（推荐）。用户在本站提交**自己合法拥有的**原书，EPUBox 交付中文译本。这正好是本仓库这套翻译流水线的天然定位——你卖的是「翻译服务」，不是「他人作品的电子版」，不需要为每一本书取得发行授权。需要在服务协议中增加条款：用户保证对提交的原书享有合法权利，并对自己的使用用途负责。
2. **只上架权利清晰的作品**：公有领域作品、CC BY / CC BY-SA（分别需署名、需相同方式共享）、已获授权的中文版，以及中文原创技术书。
3. **逐本取得授权**：向原出版社或作者取得翻译权与信息网络传播权许可，周期长、成本高，但可以保留当前的商业模式。
4. **混合模式**：主体商品走 2，个别爆款走 3；先跑通合法的部分，再决定是否值得投入授权。

无论选哪条，**在收费上线之前完成至少第 1 或第 2 条**，否则第一封权利人投诉函很可能就是结算冻结和下架。

另需提示：在中国大陆通过网络向公众提供数字化作品，可能触及《网络出版服务管理规定》的许可要求，具体是否需要办理相关许可、以及办理路径，建议就你的实际业务形态咨询专业律师或向主管部门确认。

### 5.2 格式条款风险

《消费者权益保护法》第二十六条与《民法典》第四百九十六条、第四百九十七条禁止以格式条款排除或限制消费者权利、减轻经营者责任。本套文案已做三处防御：

1. 数字化商品的退货限制**不是**笼统的「一经售出概不退款」，而是明确列举七类可退情形，并保留法定救济路径；
2. 结账页设**独立确认程序**，而不是仅在页面角落陈列文字（依据《网络购买商品七日无理由退货暂行办法》第七条、第二十条）；
3. 免责与责任限制条款末尾主动写明「若属于不公平、不合理的格式条款而对消费者不产生效力，依法承担相应责任」，避免整条无效。

**不要**在后续修改中把这些句子删掉或改成「最终解释权归本站所有」一类的表述——那会直接击穿第 3 条防御。
