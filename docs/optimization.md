# 翻译重试与纯 JSON 存储优化

2026-10-10。运行数据仍保存在 origin、mapping、plan、terms、state 五个 JSON 中，未加入数据库或依赖。

## 已实现的行为

- 内容失败按源片段、阶段和审核候选版本写入 JSON 账本，跨重启保留，重复恢复不重复计数。超时、限流和结果未知不计入内容失败。
- 第 10 次内容失败后，能够安全映射原文字节范围的片段转为句子、文本槽或表格单元格子任务。父结构和保护标记保持完整，成功子任务不重做；有有效初译时优先拆审核任务。
- 子任务最多细分 3 层，一个原始父任务的内容失败总预算为 60。没有合法边界时保留待处理状态，不猜测切分位置。
- 五个 JSON 建立记录位置索引，按需解析 payload；修改使用 copy-on-write，较大分片流式复制未变记录。提交后仅重建变化分片的索引，保留无关依赖指纹。
- 指纹保存内容摘要，不长期持有整段 JSON 字符串。源文档、准备批次和可重建证明缓存有内存预算；大型模型集合的摘要按文档计算，保持原有 canonical hash。
- 片段通过直接索引定位初始批次和源文档；读取分片摘要不再重复打包模型请求，完整验证仍保留。
- 报告不再创建 BodyJournal；正文进度缓存绑定 prepared/results 内容版本。发布可复用当前 journal，但磁盘证明或内存结果发生变化时仍重新验证。

## 实测范围与结果

使用 HCI 书籍约 1.15 GB 的五 JSON 副本，未调用模型 API，未改写原书或已生成 EPUB。

| 检查 | 结果 |
| --- | --- |
| 恢复源计划和全部成员、校验 1,806 个批次 | 86.53 秒；进程峰值 RSS 2.93 GB；15,592 个成员 |
| 完整正文断点恢复（含源计划及全部证明） | 581.82 秒（约 9 分 42 秒）；进程峰值 RSS 4.07 GB；全部 15,408 单元及历史 HTTP 数校验通过 |
| 未变化的完整证明再次核验 | 1.26 秒 |
| 第一次读取正文进度 | 约 3 秒 |
| 同版本正文进度再次读取 | 约 0.1 毫秒；不重建正文模型 |
| 完整报告生成、流式提交与证明摘要对照 | 11.13 秒；进程峰值 RSS 1.14 GB |
| 历史分片证明兼容性 | 159 个旧格式分片计划及组合证明摘要全部一致 |
| 报告写入后的数据一致性 | 15,408/15,408 已接受；累计 HTTP 4,924；请求、响应、译文、人工/分片证明及源映射摘要未变化 |

独立单文件实验（373.6 MB mapping.json）：原 json.load 约 0.81 秒、私有内存峰值约 1.12 GB；严格索引约 1.07 秒、私有峰值约 89.7 MB。该实验说明内存减少，并不说明首次解析变快。私有内存与 RSS 是不同指标，不混合计算降幅。

上述结果是对应阶段的样本测量，不是全流程 CPU 降幅，也不是五 HTML 同时进行网络翻译的峰值。此前约 15 GB 的人工补全进程涵盖更多阶段，不能直接与源计划恢复的 2.93 GB 相除宣称收益。

在项目根目录执行以下命令。先准备完整且无待恢复事务的工作目录副本；默认基准只读取检查点，不发送模型请求或生成 EPUB。`--journal` 会核验完整证明，并可能在副本中保存派生请求 frame：

```bash
.venv/bin/python -m benchmarks.storage /path/to/checkpoint-copy
.venv/bin/python -m benchmarks.storage /path/to/checkpoint-copy --ready
.venv/bin/python -m benchmarks.storage /path/to/checkpoint-copy --journal
.venv/bin/pytest -q
.venv/bin/ruff check .
.venv/bin/pyright
```

## 保留的限制

- 固定五个 JSON 意味着改变大分片仍须复制该分片，不能实现记录级磁盘写入。接近 400 MB 上限时的跨分片再平衡保留原兼容算法，仍可能出现较高瞬时内存。
- 恢复阶段仍需验证完整源计划，成员和小型全局映射仍保留；当前未将所有初始化工作都改为逐文档执行。
- 报告完整生成与落盘在此样本上约 11 秒；毫秒级结果仅适用于同版本正文进度查询。完整冷恢复仍需约 9 分 42 秒并可能占满一个 CPU 核心；4.07 GB 实测峰值略高于最初 4 GB 的目标，不作为硬内存上限承诺。
- 没有合法、安全的源码边界或审核译文无法可靠对齐时，任务会明确保留待处理状态，不能保证任意内容都自动通过模型审核。
